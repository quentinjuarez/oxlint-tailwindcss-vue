# oxlint-tailwindcss-vue 0.4 `--fix` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `oxlint-tailwindcss-vue --fix` and `lint({ fix: true })` apply the fixes of the user's Tailwind rules to the class values of `.vue` templates, never write a wrong character, and report what remains.

**Architecture:** Per config group, the virtual files are written in a fix mode where each `\r\n` inside a rewrite becomes a space and a `\n`, and oxlint runs with `--fix` until no virtual file changes (10 passes at most). A pure copy-back compares the Babel tokens of each virtual file before and after the passes, pairs the `;__(...)` regions, and turns every changed string or template part into a replacement in the `.vue` text, or refuses its region with a code. Files are written once every group is fixed, only when unchanged on disk, then the normal pipeline reports what remains.

**Tech Stack:** TypeScript (ESM, NodeNext), `@babel/parser` 8.1 (`tokens: true`), `@vue/compiler-sfc` 3.5, Vitest with fast-check, oxlint 1.94 and oxlint-tailwindcss 1.17.2.

**Spec:** `docs/design.md`, section "Fixes (0.4)", approved on 2026-11-25. Read it before Task 1, with `.claude/skills/virtual-file-contract/SKILL.md`.

```ts
export type FixRefusalCode =
  | 'parse-error'
  | 'regions-changed'
  | 'skeleton-changed'
  | 'source-mismatch'
  | 'unsafe-value'
  | 'line-break'
  | 'changed-on-disk';

export interface Refusal {
  code: Exclude<FixRefusalCode, 'changed-on-disk'>;
  offset: number; // UTF-16 index in CopyBackResult.text
}

export interface CopyBackInput {
  source: string; // the .vue text that was virtualized
  before: string; // its fix-mode virtual file, as written before the passes
  after: string; // the same file after the passes
  rewrites: readonly Rewrite[]; // virtualizeForFix(source).rewrites
}

export interface CopyBackResult {
  text: string; // source with the accepted replacements, or source itself
  refused: Refusal[]; // in source order
}

export function copyBack(input: CopyBackInput): CopyBackResult;
```

The rules the signature leaves open:

1. Tokenize `before` and `after` with `parse(code, { sourceType: 'module', plugins: ['typescript'], tokens: true })`. A token's label is `type.label` when `type` is an object, else `type`; drop `CommentBlock`, `CommentLine` and `eof`. When `after` throws, return `{ text: source, refused: [{ code: 'parse-error', offset: 0 }] }`. When `before` throws, throw: it is a bug.
2. A region starts at a `;` token followed by a `name` token whose value is `__` or `___` and a `(` token, and ends at the matching `)` (count `(` and `)` tokens only); the scan goes on after it. The regions of `before` pair in order with the `rewrites` whose `kind` is not `comment`; a different count is a bug: throw. When `before` and `after` have different region counts, return `regions-changed` at offset 0 and `text: source`.
3. Value tokens are labeled `string`, `` ...` `` and `...${`; Babel 8 template tokens hold their delimiters. A value's content spans `[start + 1, end - 1]`, or `[start + 1, end - 2]` for `...${`. A region's skeleton is the label of every token and the value of every token that is not a value token. Different skeletons: `skeleton-changed`.
4. For each value whose content changed, with `original` the `source` text at the before value's content span:
   - `source-mismatch` when `original.replaceAll('\r\n', ' \n')` differs from the before content;
   - `line-break` when `original` has a `\r` not followed by `\n`, or holds both `\r\n` and a `\n` with no `\r` before it, or when the after content has more `\n` than the before content;
   - the new text is the after content, where every `\n`, with one space just before it when there is one, becomes `\r\n` if `original` holds `\r\n`;
   - `unsafe-value` when the new text matches ``/[\\`]|\$\{|&[#A-Za-z]/``, holds the quote of its attribute, or, when the attribute value has no quotes, matches `/[\t\n\f\r "'=<>]/`. The quote is the first character after the first `=` of the attribute (`rewrite.span` covers the whole attribute) and its HTML whitespace, when it is `"` or `'`.
5. The first failing check refuses the region, and a refused region keeps all its values. One refusal per region, at `rewrite.span.start` shifted by the length changes of the accepted replacements that end before it. Accepted replacements are applied from the end of the source to the start.

```ts
import { describe, expect, it } from 'vitest';

import { copyBack } from '../../src/fix/copy-back.js';
import type { VirtualizeOptions } from '../../src/virtual/types.js';
import { virtualizeForFix } from '../../src/virtual/virtualize.js';

function template(...lines: string[]): string {
  return ['<template>', ...lines, '</template>', ''].join('\n');
}

function fixWith(
  source: string,
  edits: [from: string, to: string][],
  options?: VirtualizeOptions,
) {
  const { code, rewrites } = virtualizeForFix(source, options);
  if (code === null) throw new Error('no virtual file');
  let after = code;
  for (const [from, to] of edits) {
    if (!after.includes(from))
      throw new Error(`not in the virtual file: ${from}`);
    after = after.replace(from, to);
  }
  return copyBack({ source, before: code, after, rewrites });
}

const unchanged = (source: string, code: string, offset: number) => ({
  text: source,
  refused: [{ code, offset }],
});

describe('copyBack', () => {
  it('copies a changed static value', () => {
    expect(
      fixWith(template('  <p class="p-4 flex flex">x</p>'), [
        ['`p-4 flex flex`', '`flex p-4`'],
      ]),
    ).toEqual({ text: template('  <p class="flex p-4">x</p>'), refused: [] });
  });

  it('copies the changed strings of a bound value', () => {
    expect(
      fixWith(
        template(`  <p :class="['mt-2 mb-2', ok && 'px-2 py-2']">x</p>`),
        [
          ["'mt-2 mb-2'", "'my-2'"],
          ["'px-2 py-2'", "'p-2'"],
        ],
      ),
    ).toEqual({
      text: template(`  <p :class="['my-2', ok && 'p-2']">x</p>`),
      refused: [],
    });
  });

  it('copies a changed template part next to an expression', () => {
    expect(
      fixWith(
        template('  <p :class="`text-red-500 text-red-500 ${size}`">x</p>'),
        [['`text-red-500 text-red-500 ${', '`text-red-500 ${']],
      ),
    ).toEqual({
      text: template('  <p :class="`text-red-500 ${size}`">x</p>'),
      refused: [],
    });
  });

  it('copies the values of an attribute from the settings', () => {
    expect(
      fixWith(
        template(`  <UCard :ui="{ root: 'p-2 p-2' }" />`),
        [["'p-2 p-2'", "'p-2'"]],
        { attributes: ['ui'] },
      ),
    ).toEqual({
      text: template(`  <UCard :ui="{ root: 'p-2' }" />`),
      refused: [],
    });
  });

  it('applies replacements from the end, so a shorter value moves none of the others', () => {
    expect(
      fixWith(
        template(
          '  <p class="flex flex p-2">x</p>',
          '  <i class="m-2 m-2">y</i>',
        ),
        [
          ['`flex flex p-2`', '`flex p-2`'],
          ['`m-2 m-2`', '`m-2`'],
        ],
      ),
    ).toEqual({
      text: template('  <p class="flex p-2">x</p>', '  <i class="m-2">y</i>'),
      refused: [],
    });
  });

  it('copies a value after non-ASCII text on the same line', () => {
    expect(
      fixWith(
        template('  <p title="caf\u{e9} \u{1F600}" class="p-2 p-2">x</p>'),
        [['`p-2 p-2`', '`p-2`']],
      ),
    ).toEqual({
      text: template('  <p title="caf\u{e9} \u{1F600}" class="p-2">x</p>'),
      refused: [],
    });
  });

  it('leaves a skipped attribute as it is', () => {
    expect(
      fixWith(template('  <p class="p-2 &amp; p-2" :class="`m-2 m-2`">x</p>'), [
        ['`m-2 m-2`', '`m-2`'],
      ]),
    ).toEqual({
      text: template('  <p class="p-2 &amp; p-2" :class="`m-2`">x</p>'),
      refused: [],
    });
  });

  it('ignores the disable comments between values', () => {
    const comment =
      '  <!-- oxlint-disable-next-line tailwindcss/no-unknown-classes -->';
    expect(
      fixWith(template(comment, '  <p class="p-2 p-2">x</p>'), [
        ['`p-2 p-2`', '`p-2`'],
      ]),
    ).toEqual({
      text: template(comment, '  <p class="p-2">x</p>'),
      refused: [],
    });
  });

  it('returns the source when the virtual file did not change', () => {
    const source = template('  <p class="p-2 p-2">x</p>');
    expect(fixWith(source, [])).toEqual({ text: source, refused: [] });
  });

  it('writes CRLF back in a changed multi-line value', () => {
    const source =
      '<template>\r\n  <p class="mt-2\r\n      mb-2 mt-2">x</p>\r\n</template>\r\n';
    expect(
      fixWith(source, [['`mt-2 \n      mb-2 mt-2`', '`mt-2 \n      mb-2`']]),
    ).toEqual({
      text: '<template>\r\n  <p class="mt-2\r\n      mb-2">x</p>\r\n</template>\r\n',
      refused: [],
    });
  });

  it('writes CRLF back when a fix dropped the space before the line break', () => {
    const source =
      '<template>\r\n  <p class="mt-2\r\n      mb-2 mt-2">x</p>\r\n</template>\r\n';
    expect(
      fixWith(source, [['`mt-2 \n      mb-2 mt-2`', '`mt-2\n      mb-2`']])
        .text,
    ).toBe(
      '<template>\r\n  <p class="mt-2\r\n      mb-2">x</p>\r\n</template>\r\n',
    );
  });

  it('keeps a real space before a CRLF', () => {
    const source =
      '<template>\r\n  <p class="mt-2 \r\n  mb-2 mb-2">x</p>\r\n</template>\r\n';
    expect(
      fixWith(source, [['`mt-2  \n  mb-2 mb-2`', '`mt-2  \n  mb-2`']]).text,
    ).toBe(
      '<template>\r\n  <p class="mt-2 \r\n  mb-2">x</p>\r\n</template>\r\n',
    );
  });

  it('refuses every fix of a file whose fixed virtual file does not parse', () => {
    const source = template(
      '  <p class="p-2 p-2">x</p>',
      '  <i class="m-2 m-2">y</i>',
    );
    expect(
      fixWith(source, [
        ['`p-2 p-2`)', '`p-2`'],
        ['`m-2 m-2`', '`m-2`'],
      ]),
    ).toEqual(unchanged(source, 'parse-error', 0));
  });

  it('refuses every fix of a file that gained or lost a value', () => {
    const source = template('  <p class="p-2 p-2">x</p>');
    expect(fixWith(source, [['`p-2 p-2`)', '`p-2`);__(`m-2`)']])).toEqual(
      unchanged(source, 'regions-changed', 0),
    );
  });

  it('refuses the value whose code around its strings changed, and only that one', () => {
    const source = template(
      '  <p :class="`p-2 p-2`">x</p>',
      '  <i class="m-2 m-2">y</i>',
    );
    expect(
      fixWith(source, [
        ['(`p-2 p-2`)', '([`p-2`])'],
        ['`m-2 m-2`', '`m-2`'],
      ]),
    ).toEqual({
      text: template('  <p :class="`p-2 p-2`">x</p>', '  <i class="m-2">y</i>'),
      refused: [{ code: 'skeleton-changed', offset: source.indexOf(':class') }],
    });
  });

  it('refuses a value whose text no longer matches the .vue file', () => {
    const source = template('  <p class="p-2 p-2">x</p>');
    const { code, rewrites } = virtualizeForFix(source);
    const edited = template('  <p class="p-2 p-3">x</p>');
    expect(
      copyBack({
        source: edited,
        before: code as string,
        after: (code as string).replace('`p-2 p-2`', '`p-2`'),
        rewrites,
      }),
    ).toEqual(unchanged(edited, 'source-mismatch', edited.indexOf('class')));
  });

  it('refuses a value that would hold the quote of its attribute', () => {
    const double = template('  <p class="p-2">x</p>');
    expect(fixWith(double, [['`p-2`', '`content-["x"]`']])).toEqual(
      unchanged(double, 'unsafe-value', double.indexOf('class')),
    );
    const single = template("  <p class='p-2'>x</p>");
    expect(fixWith(single, [['`p-2`', '`content-["x"]`']]).text).toBe(
      template(`  <p class='content-["x"]'>x</p>`),
    );
  });

  it.each([
    ['a backslash', String.raw`'p-2\\'`],
    ['a backtick', "'p-2 `'"],
    ['${', "'p-${2}'"],
    ['a named character reference', "'p-2 &amp;'"],
    ['a numeric character reference', "'p-2 &#38;'"],
  ])('refuses a value holding %s', (_, string) => {
    const source = template(`  <p :class="'p-2 p-2'">x</p>`);
    expect(fixWith(source, [["'p-2 p-2'", string]])).toEqual(
      unchanged(source, 'unsafe-value', source.indexOf(':class')),
    );
  });

  it('accepts an arbitrary variant with &', () => {
    expect(
      fixWith(template('  <p class="p-2 p-2">x</p>'), [
        ['`p-2 p-2`', '`[&_p]:p-2`'],
      ]).text,
    ).toBe(template('  <p class="[&_p]:p-2">x</p>'));
  });

  it('refuses whitespace in a value without quotes', () => {
    const source = template('  <p class=p-2 >x</p>');
    expect(fixWith(source, [['`p-2`', '`p-2 m-2`']])).toEqual(
      unchanged(source, 'unsafe-value', source.indexOf('class')),
    );
    expect(fixWith(source, [['`p-2`', '`m-2`']]).text).toBe(
      template('  <p class=m-2 >x</p>'),
    );
  });

  it('refuses a fix that adds a line break', () => {
    const source = template('  <p class="p-2 flex">x</p>');
    expect(fixWith(source, [['`p-2 flex`', '`p-2\nflex`']])).toEqual(
      unchanged(source, 'line-break', source.indexOf('class')),
    );
  });

  it('refuses a changed value with a lone CR, or with both CRLF and LF', () => {
    const lone = '<template><p class="flex\rp-2 p-2">x</p></template>';
    expect(fixWith(lone, [['`flex\rp-2 p-2`', '`flex\rp-2`']])).toEqual(
      unchanged(lone, 'line-break', lone.indexOf('class')),
    );
    const mixed =
      '<template>\r\n  <p class="flex\r\n  p-2\n  p-2">x</p>\r\n</template>\r\n';
    expect(
      fixWith(mixed, [['`flex \n  p-2\n  p-2`', '`flex \n  p-2`']]),
    ).toEqual(unchanged(mixed, 'line-break', mixed.indexOf('class')));
  });

  it('reports a refusal at its attribute in the text as written', () => {
    const result = fixWith(
      template('  <p class="flex flex p-2">x</p>', '  <i class="m-2">y</i>'),
      [
        ['`flex flex p-2`', '`flex p-2`'],
        ['`m-2`', '`m-2\nm-3`'],
      ],
    );
    expect(result.text).toBe(
      template('  <p class="flex p-2">x</p>', '  <i class="m-2">y</i>'),
    );
    expect(result.refused).toEqual([
      { code: 'line-break', offset: result.text.indexOf('class="m-2"') },
    ]);
  });

  it('throws when the virtual file before the passes breaks its invariants', () => {
    const source = template('  <p class="p-2">x</p>');
```

**Interfaces:**

- Consumes: `virtualizeForFix` (Task 1); `copyBack`, `Refusal`, `FixRefusalCode` (Task 2).
- Produces:
  - `DeriveInput.fix?: boolean`. When true, `deriveConfig` leaves `<alias>/enforce-consistent-line-wrapping` out of `rules` and out of the `rules` of every override; an override left without rules is dropped, as today.
  - `lintVirtualFiles(oxlint, options)` takes `fix?: boolean` and then passes `--fix`.
  - `fixVirtualFiles(oxlint: OxlintInstall, options: { configPath: string; cwd: string; files: readonly string[]; signal?: AbortSignal }): Promise<{ stderr: string }>` in `src/oxlint/commands.ts`. Pass 1 runs `lintVirtualFiles` with `fix: true` on every file; each later pass runs only the files the previous pass changed (compared by content); it stops after a pass that changed nothing, or after `MAX_FIX_PASSES = 10` passes. `stderr` joins the stderr of the passes.
  - In `src/lint.ts`: `LintOptions.fix?: boolean`; `export interface RefusedFix extends Located { code: FixRefusalCode }`; `FileReport` gains `fixed?: true` and `refusedFixes?: RefusedFix[]`, set only when the file was written and when the list is not empty.
  - `src/index.ts` exports the types `FixRefusalCode` and `RefusedFix`.

The flow in `src/lint.ts`:

- `run()` builds one `GroupRun` per config group as today. With `options.fix`, before the report loop, every group runs in turn through `fixGroup({ ...group, dir: join(temp.path, 'fix', String(index)) })`; after the last group, `signal?.throwIfAborted()`, then `writeFixes(planned)`. Writing after every group means that a tool failure in any group writes nothing. The stderr of the fix passes joins the list that becomes `oxlintStderr`. After the report loop, each `FileReport` gets the `fixed` and `refusedFixes` of its file.
- `fixGroup(group: GroupRun): Promise<{ planned: PlannedFix[]; stderr: string }>`, with `interface PlannedFix { file: string; source: string; text: string; refused: Refusal[] }`. A group whose config does not load oxlint-tailwindcss gives nothing. Otherwise each file is read and virtualized with `virtualizeForFix` (a `null` code leaves the file out), the virtual files and the config derived with `fix: true` are written, and `fixVirtualFiles` runs. A file whose virtual file did not change is left out; every other one gives `copyBack({ source, before, after, rewrites })`.
- Extract from `lintGroup` the steps both phases share, and use them there: `writeVirtualFile(group: GroupRun, file: string, code: string): string` (mirror path, mkdir, write; returns the virtual path) and `writeGroupConfig(group: GroupRun, printed: PrintedConfig, fix: boolean): { derived: Record<string, unknown>; configPath: string; childCwd: string }`. `virtualizeFile` takes a fourth parameter, `fix: boolean`.
- `writeFixes(planned: readonly PlannedFix[]): Map<string, Pick<FileReport, 'fixed' | 'refusedFixes'>>`. When `text` equals `source`, nothing is written and the refusals are located in `source`. Otherwise the file is read again with `readSource`: when it differs from `source`, nothing is written and its only refusal is `changed-on-disk` at line 1, column 1; else `text` is written and the refusals are located in `text` (`locator`).
