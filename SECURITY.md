# Security policy

## Supported versions

Only the latest release of `oxlint-tailwindcss-vue` receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting instead:
open the **Security** tab of the repository and choose **Report a vulnerability**.

You can expect an acknowledgement within a few days. Confirmed issues are fixed
in a new release and credited in the release notes if you wish.

## Release integrity

Releases are published from GitHub Actions with npm trusted publishing and carry
a provenance attestation. The first version, 0.1.0, was published by hand with
two-factor authentication. No long-lived npm token exists.
